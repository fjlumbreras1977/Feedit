ACTUALIZACIÓN: CORRECCIÓN DE WIDGETS

1. Abre el repositorio Feedit en GitHub.
2. Pulsa Add file > Upload files.
3. Descomprime este ZIP y arrastra todo su contenido, conservando carpetas. Acepta reemplazar los archivos existentes.
4. Pulsa Commit changes.
5. Espera en Cloudflare hasta que el despliegue indique Successful.
6. Recarga Feedit con Ctrl+F5 y genera de nuevo el widget. Si usas un código iframe antiguo, copia el nuevo código desde Feedit y sustituye el anterior en tu web.

Esta versión corrige el error «escapeHtml is not defined», mantiene los ajustes personalizados en el código insertable y carga las fotos del widget a través de un proxy con caché. El widget va dentro de un iframe para aislar sus estilos.
